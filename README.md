# ሽክ (Shik) - Her Store & Admin Dashboard

A modern, responsive e-commerce storefront for a clothing brand, featuring a fully functional Admin Dashboard. Built with React.

---

## 🔗 Localhost Quick Links (For Local Development)

Once you run `npm run dev` in your terminal, you can access the app at these URLs:

*   🛍️ **Main Storefront:** [http://localhost:5180](http://localhost:5180)
*   🔐 **Admin Dashboard:** [http://localhost:5180/#admin](http://localhost:5180/#admin)
*   ⚙️ **Backend API:** [http://localhost:5000](http://localhost:5000) *(Requires the backend server to be running)*

---

## 🚀 Features
*   **Storefront:** Home page, Shop, Collections, and New Arrivals.
*   **Shopping Cart:** Add to bag, adjust quantities, and seamless checkout flow.
*   **Customer Account:** Simple local registration/login for buyers.
*   **Admin Dashboard:** Secure login, Sales overview, Inventory management, Order tracking, and Add Product functionality (with image upload).
