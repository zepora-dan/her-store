# HER

A girly online store for clothing, shoes, makeup and luxury products, built with React and Vite.

## Run it

1. `npm install`
2. `npm run dev`
3. Open [http://localhost:5180](http://localhost:5180)

## How it works

- Products live in `src/data.js`. Add photos to `public/images` and set `photo: '/images/name.jpg'`.
- Visitors can filter by category, search, sort by price, save favourites and fill a bag.
- The bag and favourites are saved in the browser, so they stay after a refresh.
